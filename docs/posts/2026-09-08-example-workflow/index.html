Static figure

Static figures (like the ones on Zack Labe’s site) are the easiest way to share results — just a matplotlib plot saved into the rendered page.

Code 
fig, ax = plt.subplots(figsize=(7, 5))
im = ax.pcolormesh(lon, lat, precip, cmap="Blues", shading="auto")
ax.set_title("Example precipitation field (synthetic)")
ax.set_xlabel("Longitude")
ax.set_ylabel("Latitude")
fig.colorbar(im, ax=ax, label="mm/day")
plt.show()
