Lets you pick any currently active NHC storm (Atlantic, East Pacific, or Central Pacific) and view a composite rainfall accumulation (in) and max sustained wind (mph) field within 500 km of its forecast track, using HAFS.

What this page does

Every time this page is rendered (including the scheduled daily rebuild — see the note at the bottom), it:

  1. Pulls every currently active NHC storm across the Atlantic, East Pacific, and Central Pacific basins.
  2. For each one, downloads its official forecast track and classifies each point by Saffir-Simpson category.
  3. Pulls matching HAFS (Hurricane Analysis and Forecast System) fields – accumulated precipitation and a period-maximum surface wind – masks each field to a 500 km circle around the storm’s forecast position at each step, sums rainfall across steps, and takes the running maximum wind seen at each pixel across the entire forecast period.
  4. Renders one plot per storm (as a real PNG file, not an embedded image — see the caveats), and gives you a dropdown to switch between them.

The steps below are broken into the same stages, each ending with a small table or plot summarizing what that stage produced – useful both for following along and for spotting a bad storm before it reaches the final map.

Important

This dropdown does not recompute anything live. The site is static — there’s no server behind it. At render time, this code pre-computes a plot for every active storm; the dropdown just shows/hides a pre-rendered image. What you see is only as fresh as the last render (daily, via cron).

def run_stage(label, fn):
    """
    Run a zero-argument callable for one storm at one pipeline stage,
    honoring DEBUG_RAISE. Returns fn()'s result, or None if this storm
    failed at this stage (and should be dropped from later stages).
    """
    try:
        return fn()
    except Exception:
        if DEBUG_RAISE:
            raise
        tb = traceback.format_exc().replace("--", "- -")
        failures.append((label, tb))
        return None


def classify_category(wind_kt):
    if wind_kt is None or (isinstance(wind_kt, float) and np.isnan(wind_kt)):
        return "Unknown"
    if wind_kt < 34:
        return "TD"
    if wind_kt < 64:
        return "TS"
    if wind_kt < 96:
        return "HU"
    return "MH"


def geodesic_circle(center_lon, center_lat, radius_km, n=72):
    az = np.linspace(0, 360, n, endpoint=True)
    lon2, lat2, _ = GEOD.fwd(np.full(n, center_lon), np.full(n, center_lat),
                              az, np.full(n, radius_km * 1000.0))
    return lon2, lat2


def circle_mask_km(lon2d, lat2d, center_lon, center_lat, radius_km):
    n = lon2d.size
    grid_lons = np.where(lon2d.ravel() > 180, lon2d.ravel() - 360, lon2d.ravel())
    _, _, dist_m = GEOD.inv(np.full(n, center_lon), np.full(n, center_lat), grid_lons, lat2d.ravel())
    return (dist_m / 1000.0 <= radius_km).reshape(lon2d.shape)


def smooth_for_contour(da, sigma=WIND_SMOOTH_SIGMA):
    """
    Gaussian-smooth a 2D field for prettier contour lines, without letting
    NaN (outside the 500 km composite footprint) bleed a false gradient into
    the valid region. Standard "fill with 0, smooth the validity mask the
    same way, divide back out" trick, then re-mask anywhere the smoothed
    validity weight is too low to trust.
    """
    values = da.values
    valid = np.isfinite(values)
    if not valid.any():
        return da
    filled = np.where(valid, values, 0.0)
    smoothed = gaussian_filter(filled, sigma=sigma)
    weight = gaussian_filter(valid.astype(float), sigma=sigma)
    with np.errstate(invalid="ignore", divide="ignore"):
        result = smoothed / weight
    result[weight < 0.2] = np.nan
    return da.copy(data=result)

def first_data_var(ds):
    skip = {"latitude", "longitude", "time", "step", "valid_time",
            "surface", "isobaricInhPa", "heightAboveGround"}
    for name in ds.data_vars:
        if name not in skip:
            return ds[name]
    raise RuntimeError(f"No data variable found in dataset: {list(ds.data_vars)}")


def best_matching_bucket(H, var_search, end_hour):
    """Widest available bucket for var_search that ends exactly at end_hour."""
    try:
        inv = H.inventory(var_search)
    except Exception:
        return None
    if inv is None or len(inv) == 0:
        return None
    pattern = re.compile(r"(\d+)-(\d+) hour")
    best, best_width = None, -1
    for _, row in inv.iterrows():
        m = pattern.search(str(row.get("forecast_time", "")))
        if not m:
            continue
        start, end = int(m.group(1)), int(m.group(2))
        if end == end_hour and (end - start) > best_width:
            best, best_width = row["search_this"], end - start
    return best

def load_track(storm):
    """Download a storm's official NHC forecast track and merge in its current position."""
    zip_url = storm["forecastTrack"]["zipFile"]
    r = requests.get(zip_url, timeout=60)
    r.raise_for_status()
    zf = zipfile.ZipFile(io.BytesIO(r.content))
    pts_candidates = [n for n in zf.namelist() if n.lower().endswith("_pts.shp")]
    if not pts_candidates:
        raise RuntimeError(f"No '*_pts.shp' in track archive for {storm['id']}")
    extract_dir = f"/tmp/nhc_track_{storm['id']}"
    zf.extractall(extract_dir)
    track_raw = gpd.read_file(f"{extract_dir}/{pts_candidates[0]}")

    tau_col = "TAU" if "TAU" in track_raw.columns else next(
        c for c in track_raw.columns if c.upper() == "TAU"
    )
    track_raw = track_raw.sort_values(tau_col).reset_index(drop=True)

    wind_col = next(
        (c for c in ["MAXWIND", "INTENSITY", "VMAX", "WIND"] if c in track_raw.columns), None
    )
    wind_kt_series = (
        track_raw[wind_col].astype(float) if wind_col else pd.Series([np.nan] * len(track_raw))
    )

    issuance = pd.to_datetime(storm["forecastTrack"]["issuance"])
    forecast_pts = pd.DataFrame({
        "tau_h": track_raw[tau_col].astype(float),
        "lon": track_raw.geometry.x,
        "lat": track_raw.geometry.y,
        "wind_kt": wind_kt_series,
    })
    forecast_pts["valid_time"] = issuance + pd.to_timedelta(forecast_pts["tau_h"], unit="h")

    init_wind_kt = pd.to_numeric(pd.Series([storm.get("intensity")]), errors="coerce").iloc[0]
    init_row = pd.DataFrame([{
        "tau_h": 0.0, "lon": storm["longitudeNumeric"], "lat": storm["latitudeNumeric"],
        "wind_kt": init_wind_kt, "valid_time": pd.to_datetime(storm["lastUpdate"]),
    }])
    track = (
        pd.concat([init_row, forecast_pts], ignore_index=True)
        .drop_duplicates(subset="tau_h").sort_values("tau_h").reset_index(drop=True)
    )
    track["category"] = track["wind_kt"].apply(classify_category)
    track["color"] = track["category"].map(CATEGORY_COLORS)

    atcf_id = atcf_storm_id(storm["id"])

    # Herbie resolves the HAFS storm-following file path by scraping NOMADS's
    # live "active storm" registry for this storm's name; a brand-new/just
    # -designated storm isn't in that registry until NOMADS/HAFS catch up,
    # and Herbie's own error for that case is an opaque AttributeError deep
    # in its HAFS template. Check for it up front with a clear message,
    # instead of every fetch in the next stage failing the same opaque way.
    if hafs_storms.id_to_name.get(atcf_id) is None:
        raise RuntimeError(
            f"HAFS has no storm-following guidance for {storm['id']} (ATCF id "
            f"'{atcf_id}') yet -- it isn't in NOMADS's active HAFS storm "
            f"registry (hafs/prod/inphfsa listing) right now. This is normal "
            f"for a storm that was just designated; it should appear once "
            f"NHC/NOMADS register it."
        )

    return {"track": track, "atcf_id": atcf_id}

3. Fetch matching HAFS fields and composite them into each storm’s outlook

def composite_storm_fields(entry):
    """
    Fetch HAFS precip/wind for every window along the track, mask each to a
    500 km circle around that window's forecast position, and combine them:
    rainfall summed across windows, wind as the running max seen at each
    pixel across the whole forecast period.
    """
    storm, track, atcf_id = entry["storm"], entry["track"], entry["atcf_id"]

    lat_min, lat_max = track["lat"].min() - BBOX_PAD_DEG, track["lat"].max() + BBOX_PAD_DEG
    lon_min, lon_max = track["lon"].min() - BBOX_PAD_DEG, track["lon"].max() + BBOX_PAD_DEG

    # HAFS's storm.atm output is a MOVING nest -- each forecast hour's file
    # is centered on the storm's position at that hour, unlike GFS's single
    # global grid. A fixed crop can end up empty. Instead we define one
    # common target grid ourselves and interpolate every field onto it.
    target_lat = None
    target_lon = None

    def regrid_to_common(da):
        nonlocal target_lat, target_lon
        da = da.sortby("latitude").sortby("longitude")
        lon_vals = da["longitude"].values
        if lon_vals.size and lon_vals.max() > 180:
            da = da.assign_coords(longitude=(((da["longitude"] + 180) % 360) - 180)).sortby("longitude")

        if target_lat is None:
            lat_vals = da["latitude"].values
            lon_vals2 = da["longitude"].values
            lat_res = abs(float(lat_vals[1] - lat_vals[0])) if lat_vals.size > 1 else 0.05
            lon_res = abs(float(lon_vals2[1] - lon_vals2[0])) if lon_vals2.size > 1 else 0.05
            target_lat = np.arange(lat_min, lat_max, lat_res)
            target_lon = np.arange(lon_min, lon_max, lon_res)

        out = da.interp(latitude=target_lat, longitude=target_lon, method="linear")
        if bool(out.isnull().all()):
            raise RuntimeError(
                f"Regridding produced no valid data at all (target lat "
                f"[{lat_min:.2f},{lat_max:.2f}], lon [{lon_min:.2f},{lon_max:.2f}]; "
                f"native lat [{da['latitude'].values.min():.2f},{da['latitude'].values.max():.2f}], "
                f"lon [{da['longitude'].values.min():.2f},{da['longitude'].values.max():.2f}])"
            )
        return out

    def fxx_for(valid_time):
        hours = (valid_time - hafs_cycle).total_seconds() / 3600.0
        return max(int(round(hours)), 0)

    def fetch_precip_window(fxx0, fxx1):
        """
        Precip accumulated over (fxx0, fxx1] (mm). Prefers a direct HAFS
        bucket spanning exactly this window (avoids differencing two
        "since-init" cumulative fields, which assumes a fixed grid the way
        GFS has -- HAFS's nest moves, so two cumulative snapshots may not
        share the same actual coverage, and differencing them can produce
        bad values where they don't line up).
        """
        H1 = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx1, storm=atcf_id, verbose=False)
        direct = best_matching_bucket(H1, ":APCP:surface:", fxx1)
        if direct is not None:
            m = re.search(r"(\d+)-(\d+) hour", direct)
            if m and int(m.group(1)) == fxx0:
                return regrid_to_common(first_data_var(H1.xarray(direct))).clip(min=0)

        a1 = regrid_to_common(first_data_var(H1.xarray(f":APCP:surface:0-{fxx1} hour acc fcst")))
        if fxx0 == 0:
            return a1.clip(min=0)
        H0 = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx0, storm=atcf_id, verbose=False)
        a0 = regrid_to_common(first_data_var(H0.xarray(f":APCP:surface:0-{fxx0} hour acc fcst")))
        return (a1 - a0).clip(min=0)

    def fetch_wind_max(fxx):
        H = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx, storm=atcf_id, verbose=False)
        search = best_matching_bucket(H, ":WIND:10 m above ground:", fxx)
        if search is None:
            search = f":WIND:10 m above ground:{max(fxx - 1, 0)}-{fxx} hour max fcst"
        return regrid_to_common(first_data_var(H.xarray(search)))

    precip_total = wind_running_max = lon2d = lat2d = None
    skipped_windows = []

    for i in range(1, len(track)):
        t0, t1 = track.iloc[i - 1], track.iloc[i]
        fxx0, fxx1 = fxx_for(t0["valid_time"]), fxx_for(t1["valid_time"])

        if fxx0 > HAFS_MAX_FXX or fxx1 > HAFS_MAX_FXX:
            skipped_windows.append((t0["tau_h"], t1["tau_h"], fxx0, fxx1, "beyond HAFS max lead time"))
            continue

        try:
            precip_window = fetch_precip_window(fxx0, fxx1)
            wind_window = np.fmax(fetch_wind_max(fxx0), fetch_wind_max(fxx1))
            print(f"<!-- {storm['id']} window {t0['tau_h']:.0f}h-{t1['tau_h']:.0f}h "
                  f"(fxx {fxx0}-{fxx1}): precip range "
                  f"[{float(precip_window.min()):.2f},{float(precip_window.max()):.2f}] mm, "
                  f"wind range [{float(wind_window.min()):.2f},{float(wind_window.max()):.2f}] m/s -->")
        except Exception:
            tb = traceback.format_exc().replace("--", "- -")
            skipped_windows.append((t0["tau_h"], t1["tau_h"], fxx0, fxx1, tb))
            continue

        if lon2d is None:
            lon2d, lat2d = np.meshgrid(precip_window["longitude"], precip_window["latitude"])
            precip_total = xr.zeros_like(precip_window)
            wind_running_max = xr.full_like(precip_window, np.nan)

        mask = circle_mask_km(lon2d, lat2d, t1["lon"], t1["lat"], RADIUS_KM)
        mask_da = xr.DataArray(mask, dims=precip_window.dims, coords=precip_window.coords)

        # NaN inside the mask (a target-grid pixel this window's regridded HAFS
        # nest didn't actually cover -- the moving nest doesn't sit in the same
        # place at every lead time) must be treated as "this window contributed
        # zero", not left as NaN: NaN + anything = NaN, so a single window with
        # a coverage gap at a pixel would otherwise permanently blank that pixel
        # out of the whole composite, and later lead times (more windows, more
        # nest drift) have more chances for that to happen -- this is what was
        # showing up as expanding holes in the rainfall field later in a storm's
        # life.
        precip_total = precip_total + precip_window.where(mask_da, 0).fillna(0)
        wind_masked = wind_window.where(mask_da)
        wind_running_max = xr.where(
            wind_running_max.isnull(), wind_masked, np.fmax(wind_running_max, wind_masked.fillna(-np.inf)),
        )

    if precip_total is None:
        raise RuntimeError(
            f"No windows had usable HAFS data for {storm['id']} "
            f"(all {len(skipped_windows)} window(s) skipped: {skipped_windows})"
        )
    for (tau0, tau1, fxx0, fxx1, reason) in skipped_windows:
        print(f"<!-- {storm['id']}: skipped window {tau0:.0f}h-{tau1:.0f}h (fxx {fxx0}-{fxx1}): {reason} -->")

    wind_running_max = wind_running_max.where(wind_running_max > -np.inf)

    print(f"<!-- {storm['id']} FINAL: precip total range "
          f"[{float(precip_total.min()):.2f},{float(precip_total.max()):.2f}] mm "
          f"({float(precip_total.min())*MM_TO_IN:.2f} to {float(precip_total.max())*MM_TO_IN:.2f} in) -->")

    return {
        "precip_total": precip_total,
        "wind_running_max": wind_running_max,
        "windows_used": (len(track) - 1) - len(skipped_windows),
        "windows_skipped": len(skipped_windows),
    }

Method notes & caveats

  • Images are real PNG files, not embedded base64. An earlier version embedded each plot as a data:image/png;base64,... URI directly in the page. Quarto’s preview dev server tried to resolve that string as a filesystem path and crashed with File name too long. Files are now written to storm_images/ next to this post and referenced by a normal relative path, with a ?v=<timestamp> query string appended so your browser can’t serve a stale cached copy of a file that has the same name across renders — worth knowing about if you ever see an old plot persist despite a successful re-render.
  • Multi-basin labels: NHC’s own id prefix for the Atlantic is al; we display it as NA per your request, but filter on al internally.
  • Why HAFS, not HRRR: HRRR’s CONUS-only domain has no data for Central Pacific storms and misses most of the deep tropics. HAFS is NHC’s own storm-following hurricane model and covers all three basins.
  • HAFS’s moving nest: unlike GFS’s single global grid, every forecast hour’s HAFS file is centered on the storm’s position at that hour. A fixed-box crop (which worked fine for GFS) can end up empty. This code instead defines one common target grid and .interp()s every field onto it, and prints a per-window <!-- ... precip range ... --> diagnostic comment (visible in the page’s HTML source) so a bad window is easy to spot rather than silently producing an empty or wildly-out-of-range result.
  • Precip windowing: prefers a direct HAFS bucket spanning exactly the needed window; falls back to differencing two cumulative fields only if no direct match exists (differencing across a moving nest is the more fragile of the two approaches).
  • “1-minute sustained” wind: HAFS’s wind field is a model wind, not NHC’s official 1-minute convention. The ÷0.88 factor is a standard WMO approximation, not an official NHC intensity estimate.
  • DEBUG_RAISE = False: a storm that fails at any stage (e.g. no HAFS storm-following guidance published yet for a brand-new invest) is dropped from the remaining stages, with the reason logged as an HTML comment in the page source, rather than taking down the whole page. Flip it to True temporarily while chasing a specific failure to get Quarto’s own full-traceback error reporting instead.
  • Herbie’s own console output is suppressed (Herbie(..., verbose=False)) – by default it prints a ✅ Found ┊ ... line for every GRIB/IDX file it checks, which is useful interactively but was showing up as raw, ANSI-coded noise in this page’s rendered output. The per-window <!-- ... --> diagnostic comments above are this page’s own, deliberately HTML-commented-out replacement.
  • PROJ_DATA is set explicitly at the top of the setup cell, pointed at the running Python environment’s own PROJ install (sys.prefix). Without this, a PROJ_DATA/PROJ_LIB variable inherited from the shell (e.g. pointing at an older PROJ install in a different conda env) can make pyproj/cartopy/fiona load a mismatched, too-old proj.db and fail with a DATABASE.LAYOUT.VERSION.MINOR error.
  • First real run: check the per-window precip/wind range comments in the page source (or terminal) first if anything looks wrong — they’ll show exactly which window (if any) is producing bad numbers, rather than only seeing the final aggregate.

## What this page does

Every time this page is rendered (including the scheduled daily rebuild —
see the note at the bottom), it:

1. Pulls **every currently active NHC storm** across the **Atlantic**,
   **East Pacific**, and **Central Pacific** basins.
2. For each one, downloads its official forecast track and classifies each
   point by **Saffir-Simpson category**.
3. Pulls matching **HAFS** (Hurricane Analysis and Forecast System) fields
   -- accumulated precipitation and a period-maximum surface wind -- masks
   each field to a **500 km circle** around the storm's forecast position at
   each step, sums rainfall across steps, and takes the running **maximum
   wind** seen at each pixel across the *entire* forecast period.
4. Renders one plot per storm (as a real PNG file, not an embedded image —
   see the caveats), and gives you a **dropdown** to switch between them.

The steps below are broken into the same stages, each ending with a small
table or plot summarizing what that stage produced -- useful both for
following along and for spotting a bad storm before it reaches the final
map.

::: {.callout-important}
**This dropdown does not recompute anything live.** The site is static —
there's no server behind it. At render time, this code pre-computes a plot
for *every* active storm; the dropdown just shows/hides a pre-rendered
image. What you see is only as fresh as the last render (daily, via cron).
:::

```{python}
def run_stage(label, fn):
    """
    Run a zero-argument callable for one storm at one pipeline stage,
    honoring DEBUG_RAISE. Returns fn()'s result, or None if this storm
    failed at this stage (and should be dropped from later stages).
    """
    try:
        return fn()
    except Exception:
        if DEBUG_RAISE:
            raise
        tb = traceback.format_exc().replace("--", "- -")
        failures.append((label, tb))
        return None


def classify_category(wind_kt):
    if wind_kt is None or (isinstance(wind_kt, float) and np.isnan(wind_kt)):
        return "Unknown"
    if wind_kt < 34:
        return "TD"
    if wind_kt < 64:
        return "TS"
    if wind_kt < 96:
        return "HU"
    return "MH"


def geodesic_circle(center_lon, center_lat, radius_km, n=72):
    az = np.linspace(0, 360, n, endpoint=True)
    lon2, lat2, _ = GEOD.fwd(np.full(n, center_lon), np.full(n, center_lat),
                              az, np.full(n, radius_km * 1000.0))
    return lon2, lat2


def circle_mask_km(lon2d, lat2d, center_lon, center_lat, radius_km):
    n = lon2d.size
    grid_lons = np.where(lon2d.ravel() > 180, lon2d.ravel() - 360, lon2d.ravel())
    _, _, dist_m = GEOD.inv(np.full(n, center_lon), np.full(n, center_lat), grid_lons, lat2d.ravel())
    return (dist_m / 1000.0 <= radius_km).reshape(lon2d.shape)


def smooth_for_contour(da, sigma=WIND_SMOOTH_SIGMA):
    """
    Gaussian-smooth a 2D field for prettier contour lines, without letting
    NaN (outside the 500 km composite footprint) bleed a false gradient into
    the valid region. Standard "fill with 0, smooth the validity mask the
    same way, divide back out" trick, then re-mask anywhere the smoothed
    validity weight is too low to trust.
    """
    values = da.values
    valid = np.isfinite(values)
    if not valid.any():
        return da
    filled = np.where(valid, values, 0.0)
    smoothed = gaussian_filter(filled, sigma=sigma)
    weight = gaussian_filter(valid.astype(float), sigma=sigma)
    with np.errstate(invalid="ignore", divide="ignore"):
        result = smoothed / weight
    result[weight < 0.2] = np.nan
    return da.copy(data=result)

def first_data_var(ds):
    skip = {"latitude", "longitude", "time", "step", "valid_time",
            "surface", "isobaricInhPa", "heightAboveGround"}
    for name in ds.data_vars:
        if name not in skip:
            return ds[name]
    raise RuntimeError(f"No data variable found in dataset: {list(ds.data_vars)}")


def best_matching_bucket(H, var_search, end_hour):
    """Widest available bucket for var_search that ends exactly at end_hour."""
    try:
        inv = H.inventory(var_search)
    except Exception:
        return None
    if inv is None or len(inv) == 0:
        return None
    pattern = re.compile(r"(\d+)-(\d+) hour")
    best, best_width = None, -1
    for _, row in inv.iterrows():
        m = pattern.search(str(row.get("forecast_time", "")))
        if not m:
            continue
        start, end = int(m.group(1)), int(m.group(2))
        if end == end_hour and (end - start) > best_width:
            best, best_width = row["search_this"], end - start
    return best
```

```{python}
from herbie import Herbie
from herbie.models.hafs import S as hafs_storms

# The HAFS cycle we pull guidance from is the same for every storm -- the
# latest 6-hourly cycle (00/06/12/18Z) that should be complete by now.
now = datetime.now(timezone.utc)
cycle_hour = (now.hour // 6) * 6
hafs_cycle = now.replace(hour=cycle_hour, minute=0, second=0, microsecond=0)
if (now - hafs_cycle) < timedelta(hours=6):
    hafs_cycle -= timedelta(hours=6)
hafs_cycle_naive = hafs_cycle.replace(tzinfo=None)


def load_track(storm):
    """Download a storm's official NHC forecast track and merge in its current position."""
    zip_url = storm["forecastTrack"]["zipFile"]
    r = requests.get(zip_url, timeout=60)
    r.raise_for_status()
    zf = zipfile.ZipFile(io.BytesIO(r.content))
    pts_candidates = [n for n in zf.namelist() if n.lower().endswith("_pts.shp")]
    if not pts_candidates:
        raise RuntimeError(f"No '*_pts.shp' in track archive for {storm['id']}")
    extract_dir = f"/tmp/nhc_track_{storm['id']}"
    zf.extractall(extract_dir)
    track_raw = gpd.read_file(f"{extract_dir}/{pts_candidates[0]}")

    tau_col = "TAU" if "TAU" in track_raw.columns else next(
        c for c in track_raw.columns if c.upper() == "TAU"
    )
    track_raw = track_raw.sort_values(tau_col).reset_index(drop=True)

    wind_col = next(
        (c for c in ["MAXWIND", "INTENSITY", "VMAX", "WIND"] if c in track_raw.columns), None
    )
    wind_kt_series = (
        track_raw[wind_col].astype(float) if wind_col else pd.Series([np.nan] * len(track_raw))
    )

    issuance = pd.to_datetime(storm["forecastTrack"]["issuance"])
    forecast_pts = pd.DataFrame({
        "tau_h": track_raw[tau_col].astype(float),
        "lon": track_raw.geometry.x,
        "lat": track_raw.geometry.y,
        "wind_kt": wind_kt_series,
    })
    forecast_pts["valid_time"] = issuance + pd.to_timedelta(forecast_pts["tau_h"], unit="h")

    init_wind_kt = pd.to_numeric(pd.Series([storm.get("intensity")]), errors="coerce").iloc[0]
    init_row = pd.DataFrame([{
        "tau_h": 0.0, "lon": storm["longitudeNumeric"], "lat": storm["latitudeNumeric"],
        "wind_kt": init_wind_kt, "valid_time": pd.to_datetime(storm["lastUpdate"]),
    }])
    track = (
        pd.concat([init_row, forecast_pts], ignore_index=True)
        .drop_duplicates(subset="tau_h").sort_values("tau_h").reset_index(drop=True)
    )
    track["category"] = track["wind_kt"].apply(classify_category)

    atcf_id = atcf_storm_id(storm["id"])

    # -designated storm isn't in that registry until NOMADS/HAFS catch up,

    # in its HAFS template. Check for it up front with a clear message,
    # instead of every fetch in the next stage failing the same opaque way.

        raise RuntimeError(
            f"HAFS has no storm-following guidance for {storm['id']} (ATCF id "
            f"'{atcf_id}') yet -- it isn't in NOMADS's active HAFS storm "
            f"registry (hafs/prod/inphfsa listing) right now. This is normal "
            f"for a storm that was just designated; it should appear once "
            f"NHC/NOMADS register it."
        )

    return {"track": track, "atcf_id": atcf_id}
```

## 3. Fetch matching HAFS fields and composite them into each storm's outlook

```{python}
#| label: composite-fields

def composite_storm_fields(entry):
    """
    Fetch HAFS precip/wind for every window along the track, mask each to a
    500 km circle around that window's forecast position, and combine them:
    rainfall summed across windows, wind as the running max seen at each
    pixel across the whole forecast period.
    """
    storm, track, atcf_id = entry["storm"], entry["track"], entry["atcf_id"]

    lat_min, lat_max = track["lat"].min() - BBOX_PAD_DEG, track["lat"].max() + BBOX_PAD_DEG
    lon_min, lon_max = track["lon"].min() - BBOX_PAD_DEG, track["lon"].max() + BBOX_PAD_DEG

    # HAFS's storm.atm output is a MOVING nest -- each forecast hour's file
    # is centered on the storm's position at that hour, unlike GFS's single
    # global grid. A fixed crop can end up empty. Instead we define one
    # common target grid ourselves and interpolate every field onto it.
    target_lat = None
    target_lon = None

    def regrid_to_common(da):
        nonlocal target_lat, target_lon
        da = da.sortby("latitude").sortby("longitude")
        lon_vals = da["longitude"].values
        if lon_vals.size and lon_vals.max() > 180:
            da = da.assign_coords(longitude=(((da["longitude"] + 180) % 360) - 180)).sortby("longitude")

        if target_lat is None:
            lat_vals = da["latitude"].values
            lon_vals2 = da["longitude"].values
            lat_res = abs(float(lat_vals[1] - lat_vals[0])) if lat_vals.size > 1 else 0.05
            lon_res = abs(float(lon_vals2[1] - lon_vals2[0])) if lon_vals2.size > 1 else 0.05
            target_lat = np.arange(lat_min, lat_max, lat_res)
            target_lon = np.arange(lon_min, lon_max, lon_res)

        out = da.interp(latitude=target_lat, longitude=target_lon, method="linear")
        if bool(out.isnull().all()):
            raise RuntimeError(
                f"Regridding produced no valid data at all (target lat "
                f"[{lat_min:.2f},{lat_max:.2f}], lon [{lon_min:.2f},{lon_max:.2f}]; "
                f"native lat [{da['latitude'].values.min():.2f},{da['latitude'].values.max():.2f}], "
                f"lon [{da['longitude'].values.min():.2f},{da['longitude'].values.max():.2f}])"
            )
        return out

    def fxx_for(valid_time):
        hours = (valid_time - hafs_cycle).total_seconds() / 3600.0
        return max(int(round(hours)), 0)

    def fetch_precip_window(fxx0, fxx1):
        """
        Precip accumulated over (fxx0, fxx1] (mm). Prefers a direct HAFS
        bucket spanning exactly this window (avoids differencing two
        "since-init" cumulative fields, which assumes a fixed grid the way
        GFS has -- HAFS's nest moves, so two cumulative snapshots may not
        share the same actual coverage, and differencing them can produce
        bad values where they don't line up).
        """
        H1 = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx1, storm=atcf_id, verbose=False)
        direct = best_matching_bucket(H1, ":APCP:surface:", fxx1)
        if direct is not None:
            m = re.search(r"(\d+)-(\d+) hour", direct)
            if m and int(m.group(1)) == fxx0:
                return regrid_to_common(first_data_var(H1.xarray(direct))).clip(min=0)

        a1 = regrid_to_common(first_data_var(H1.xarray(f":APCP:surface:0-{fxx1} hour acc fcst")))
        if fxx0 == 0:
            return a1.clip(min=0)
        H0 = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx0, storm=atcf_id, verbose=False)
        a0 = regrid_to_common(first_data_var(H0.xarray(f":APCP:surface:0-{fxx0} hour acc fcst")))
        return (a1 - a0).clip(min=0)

    def fetch_wind_max(fxx):
        H = Herbie(hafs_cycle_naive, model=HAFS_MODEL, product=HAFS_PRODUCT, fxx=fxx, storm=atcf_id, verbose=False)
        search = best_matching_bucket(H, ":WIND:10 m above ground:", fxx)
        if search is None:
            search = f":WIND:10 m above ground:{max(fxx - 1, 0)}-{fxx} hour max fcst"
        return regrid_to_common(first_data_var(H.xarray(search)))

    precip_total = wind_running_max = lon2d = lat2d = None
    skipped_windows = []

    for i in range(1, len(track)):
        t0, t1 = track.iloc[i - 1], track.iloc[i]
        fxx0, fxx1 = fxx_for(t0["valid_time"]), fxx_for(t1["valid_time"])

        if fxx0 > HAFS_MAX_FXX or fxx1 > HAFS_MAX_FXX:
            skipped_windows.append((t0["tau_h"], t1["tau_h"], fxx0, fxx1, "beyond HAFS max lead time"))
            continue

        try:
            precip_window = fetch_precip_window(fxx0, fxx1)
            wind_window = np.fmax(fetch_wind_max(fxx0), fetch_wind_max(fxx1))
            print(f"<!-- {storm['id']} window {t0['tau_h']:.0f}h-{t1['tau_h']:.0f}h "
                  f"(fxx {fxx0}-{fxx1}): precip range "
                  f"[{float(precip_window.min()):.2f},{float(precip_window.max()):.2f}] mm, "
                  f"wind range [{float(wind_window.min()):.2f},{float(wind_window.max()):.2f}] m/s -->")
        except Exception:
            tb = traceback.format_exc().replace("--", "- -")
            skipped_windows.append((t0["tau_h"], t1["tau_h"], fxx0, fxx1, tb))
            continue

        if lon2d is None:
            lon2d, lat2d = np.meshgrid(precip_window["longitude"], precip_window["latitude"])
            precip_total = xr.zeros_like(precip_window)
            wind_running_max = xr.full_like(precip_window, np.nan)

        mask = circle_mask_km(lon2d, lat2d, t1["lon"], t1["lat"], RADIUS_KM)
        mask_da = xr.DataArray(mask, dims=precip_window.dims, coords=precip_window.coords)

        # NaN inside the mask (a target-grid pixel this window's regridded HAFS
        # nest didn't actually cover -- the moving nest doesn't sit in the same
        # place at every lead time) must be treated as "this window contributed
        # zero", not left as NaN: NaN + anything = NaN, so a single window with
        # a coverage gap at a pixel would otherwise permanently blank that pixel
        # out of the whole composite, and later lead times (more windows, more
        # nest drift) have more chances for that to happen -- this is what was
        # showing up as expanding holes in the rainfall field later in a storm's
        # life.
        precip_total = precip_total + precip_window.where(mask_da, 0).fillna(0)
        wind_masked = wind_window.where(mask_da)
        wind_running_max = xr.where(
            wind_running_max.isnull(), wind_masked, np.fmax(wind_running_max, wind_masked.fillna(-np.inf)),
        )

    if precip_total is None:
        raise RuntimeError(
            f"No windows had usable HAFS data for {storm['id']} "
            f"(all {len(skipped_windows)} window(s) skipped: {skipped_windows})"
        )
    for (tau0, tau1, fxx0, fxx1, reason) in skipped_windows:
        print(f"<!-- {storm['id']}: skipped window {tau0:.0f}h-{tau1:.0f}h (fxx {fxx0}-{fxx1}): {reason} -->")

    wind_running_max = wind_running_max.where(wind_running_max > -np.inf)

    print(f"<!-- {storm['id']} FINAL: precip total range "
          f"[{float(precip_total.min()):.2f},{float(precip_total.max()):.2f}] mm "
          f"({float(precip_total.min())*MM_TO_IN:.2f} to {float(precip_total.max())*MM_TO_IN:.2f} in) -->")

    return {
        "precip_total": precip_total,
        "wind_running_max": wind_running_max,
        "windows_used": (len(track) - 1) - len(skipped_windows),
        "windows_skipped": len(skipped_windows),
    }


for sid, entry in list(storms_by_id.items()):
    result = run_stage(entry["storm"]["dropdown_label"], lambda entry=entry: composite_storm_fields(entry))
    if result is None:
        del storms_by_id[sid]
    else:
        entry.update(result)

composite_summary_rows = []
for entry in storms_by_id.values():
    precip, wind = entry["precip_total"], entry["wind_running_max"]
    rained_on = precip.where(precip > 0)
    composite_summary_rows.append({
        "Storm": entry["storm"]["dropdown_label"],
        "Windows used": entry["windows_used"],
        "Windows skipped": entry["windows_skipped"],
        "Max precip (mm)": round(float(precip.max()), 1),
        "Mean precip where > 0 (mm)": round(float(rained_on.mean()), 1) if bool((precip > 0).any()) else 0.0,
        "Max wind (m/s)": round(float(wind.max()), 1) if bool(np.isfinite(wind.values).any()) else None,
    })

composite_summary = (
    pd.DataFrame(composite_summary_rows) if composite_summary_rows
    else pd.DataFrame({"note": ["No storms had usable composite HAFS data."]})
)
composite_summary
```

## Method notes & caveats

- **Images are real PNG files, not embedded base64.** An earlier version
  embedded each plot as a `data:image/png;base64,...` URI directly in the
  page. Quarto's `preview` dev server tried to resolve that string as a
  filesystem path and crashed with `File name too long`. Files are now
  written to `storm_images/` next to this post and referenced by a normal
  relative path, with a `?v=<timestamp>` query string appended so your
  browser can't serve a stale cached copy of a file that has the same name
  across renders — worth knowing about if you ever see an old plot persist
  despite a successful re-render.
- **Multi-basin labels**: NHC's own id prefix for the Atlantic is `al`; we
  display it as **NA** per your request, but filter on `al` internally.
- **Why HAFS, not HRRR**: HRRR's CONUS-only domain has no data for Central
  Pacific storms and misses most of the deep tropics. HAFS is NHC's own
  storm-following hurricane model and covers all three basins.
- **HAFS's moving nest**: unlike GFS's single global grid, every forecast
  hour's HAFS file is centered on the storm's position *at that hour*. A
  fixed-box crop (which worked fine for GFS) can end up empty. This code
  instead defines one common target grid and `.interp()`s every field onto
  it, and prints a per-window `<!-- ... precip range ... -->` diagnostic
  comment (visible in the page's HTML source) so a bad window is easy to
  spot rather than silently producing an empty or wildly-out-of-range
  result.
- **Precip windowing**: prefers a direct HAFS bucket spanning exactly the
  needed window; falls back to differencing two cumulative fields only if
  no direct match exists (differencing across a moving nest is the more
  fragile of the two approaches).
- **"1-minute sustained" wind**: HAFS's wind field is a model wind, not
  NHC's official 1-minute convention. The `÷0.88` factor is a standard WMO
  approximation, not an official NHC intensity estimate.
- **`DEBUG_RAISE = False`**: a storm that fails at any stage (e.g. no HAFS
  storm-following guidance published yet for a brand-new invest) is dropped
  from the remaining stages, with the reason logged as an HTML comment in
  the page source, rather than taking down the whole page. Flip it to
  `True` temporarily while chasing a specific failure to get Quarto's own
  full-traceback error reporting instead.
- **Herbie's own console output is suppressed** (`Herbie(..., verbose=False)`)
  -- by default it prints a `✅ Found ┊ ...` line for every GRIB/IDX file it
  checks, which is useful interactively but was showing up as raw,
  ANSI-coded noise in this page's rendered output. The per-window
  `<!-- ... -->` diagnostic comments above are this page's own, deliberately
  HTML-commented-out replacement.
- **`PROJ_DATA` is set explicitly** at the top of the setup cell, pointed at
  the running Python environment's own PROJ install (`sys.prefix`). Without
  this, a `PROJ_DATA`/`PROJ_LIB` variable inherited from the shell (e.g.
  pointing at an older PROJ install in a different conda env) can make
  pyproj/cartopy/fiona load a mismatched, too-old `proj.db` and fail with a
  `DATABASE.LAYOUT.VERSION.MINOR` error.
- **First real run**: check the per-window precip/wind range comments in
  the page source (or terminal) first if anything looks wrong — they'll
  show exactly which window (if any) is producing bad numbers, rather than
  only seeing the final aggregate.
